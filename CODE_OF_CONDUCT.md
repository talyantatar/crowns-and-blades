# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, welcome newcomers, and keep criticism about the work, not the person.
Harassment, insults, discrimination, sexualised language or imagery, and publishing other people's private information are not
acceptable, in issues, pull requests, discussions or anywhere else you represent the project.

## Scope

This applies to every project space: the repository, its issues, pull requests and discussions, and to public spaces where
someone acts on behalf of the project.

## Reporting

If someone behaves in a way that breaks this code, please tell the maintainer, TaLyAn. If the
matter is private, open an issue that only asks for a private channel, without details, and the maintainer will arrange one.
Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, commits, code and issues that break this code, and may warn, temporarily ban or
permanently ban a contributor, following the Contributor Covenant's enforcement guidelines.
